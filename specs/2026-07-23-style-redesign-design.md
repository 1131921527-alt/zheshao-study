# 泽少学习助手 · 黑金焕新视觉改版 设计规格

> 方向：**黑金焕新 · 阅读优先**
> 形态：**只换皮 · 骨架不动**（保留手机壳 PWA 架构）
> 日期：2026-07-23
> 状态：待视觉签核（未开始写代码）

---

## 1. 背景与现状

`zheshao-study` 是一套**深色黑金 + 手机壳 PWA**：桌面端套 480px 手机壳、底部 5 Tab、屏幕滑动切换，可装到手机主屏。内容重（雅思单词已 77 天、AI 动态/知识/提示词、历史/地理/财经/心理长文），长文阅读页按 720px 加宽。

现有视觉问题（要在这场改版解决）：
- 金调偏"平"，层次靠描边，缺少高级光泽与浮起感。
- 阅读页排版可读但不"养眼"：字号阶梯、行距、重点框、时间线、表格都偏朴素。
- **令牌命名分裂**：首页/阅读页用 `--gold / --text-1 / --text-2`，而 `build.py` 生成的子页用 `--primary / --fg / --muted`，两套并存，后续极易改漏。

**已确认的硬约束（改版前必须知道）：**
- `assets/style.css` 不是真相源。`build.py` 第 256 行 `CSS` 常量每次运行都会**覆盖**它（316–317 行写回），且 `CLOCK_CSS` / `FRAME_CSS` 会把颜色**内联**进每个子页 / 雅思页。改子页样式必须改 `build.py` 再重跑，直接改 `assets/style.css` 会在下次每日自动化时被还原。
- `src/fix_css_dark.py`、`src/repair_build.py` 各自硬编码了一份 `:root` 和 `#0B0F17` 校验串，漏改会回退或误判。

## 2. 设计目标与原则

1. **保留黑金身份**：深底 + 金强调的"高级感"是你选定的品牌，不动底色基调。
2. **阅读优先**：长文与 77 天单词表是核心场景，排版要明显更舒服（字号、行距、层次、留白）。
3. **精致层次**：用更暖更亮的金、微提亮卡面、金辉阴影，做出"贵气但不浮夸"的层次。
4. **一致性**：全站令牌统一，杜绝改一处漏一处。
5. **无障碍**：正文对比度达 WCAG AA，支持 `prefers-reduced-motion` 关闭过渡。

---

## 3. 范围界定

### 在范围内（只换皮）
- 设计令牌取值刷新（颜色、阴影、圆角）。
- 组件样式精修（卡片、顶栏、Tab、Hero、阅读组件等）。
- 阅读页排版重做（字号阶梯、行距、标题、重点框、时间线、表格、链接）。
- 令牌命名统一（见第 8 节，分优先级）。

### 不在范围内（骨架不动）
- 不改 SPA 架构、Tab 路由、屏幕切换逻辑。
- 不改 `build.py` 的生成流程逻辑（只改其中的 CSS 常量文本）。
- 不新增板块 / 分类 / 页面结构。
- 不改 PWA 的 manifest 结构、`sw.js` 缓存逻辑（底色不变，主题色无需改）。
- 不做深/浅主题切换（本期不做，可预留）。

## 6. 组件精修（App 壳 · 改 `index.html` 内联样式）

- **卡片**（quick / link / menu）：更精致的渐变面 + 金线描边，hover 微抬升并加 `--sh-gold` 金辉，active `scale(.98)`。

- **图标底 / 徽标**：金底圆角统一，NEW 徽标用蓝 `#5B95FF` 更跳。

- **Lightbox / 底部 Sheet**：圆角与遮罩更柔和。

## 7. 改动文件矩阵（含 build.py 陷阱）

| 文件 | 角色 | 动作 |
|------|------|------|
| `index.html`（根，内联 `:root`+组件） | App 壳 / 首页 真相源（build.py 不覆盖） | 改 `:root` + 组件样式 |
| `knowledge/article.css` | 阅读页 真相源 | 改 `:root` + 阅读组件 |
| `build.py` → `CSS` 常量（第 256 行） | **生成 `assets/style.css` + 子页模板的真相源** | 改取值；重跑后重新生成 `assets/style.css` |
| `build.py` → `CLOCK_CSS`（第 28 行） | 内联时钟（每子页） | 同步金调 |
| `build.py` → `FRAME_CSS`（第 79 行） | 内联 zsframe（雅思页等） | 同步底色 / 金调 |
| `assets/style.css` | ⚠️ **被 build.py 覆盖，勿直接改** | 由 build.py 重跑生成 |
| `src/fix_css_dark.py`（第 5、77 行） | 助手脚本：`:root` + `#0B0F17` 校验 | 同步 `:root`；底色不变 → 校验串保持有效 |
| `src/repair_build.py`（第 22、94 行） | 助手脚本：`:root` + `#0B0F17` 校验 | 同上 |
| `ielts/full.html`、`ielts/day*.html` | 内联 zsframe / `FRAME_CSS` | 随生成器重跑同步，或替换内联段 |
| `manifest.webmanifest` | 主题色 `#0B0F17` | 底色不变 → **可不改** |
| `assets/icon.svg` | 黑金图标 | 可选微调渐变 |

**关键陷阱（实现时第一优先）：** 子页样式改 `build.py` 的 `CSS` / `CLOCK_CSS` / `FRAME_CSS` 常量并重跑生成；`assets/style.css` 与内联段由生成器产出，手工改会被还原。
