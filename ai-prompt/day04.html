Day 04 · AI+设计

用AI做设计，不是让它画图而已

AI能干的设计活儿比你想的多了去了
🎨核心认知：AI不只是画图工具。配色、排版、文案、版式、素材筛选——设计全流程都能用AI提效。关键是：你得告诉它"要什么感觉"，而不是"帮我画个好看的"。

大多数人用AI做设计的3个误区

  • 只会说"帮我设计一个好看的XX"——没有方向，AI只能瞎猜
  • 只用来画图——配色方案、版式规划、文案搭配这些活儿全没用上
  • 不给参考——AI不知道你喜欢什么风格，结果全靠运气

❌ 随缘式

帮我设计一个海报，主题是春日活动。

✅ 精准式

帮我规划一个春日活动海报的配色方案和版式：风格偏清新日系，主色用浅绿+白，标题占画面40%，底部放活动信息，中间留大面积留白。

AI在设计里能干5件事

1配色方案：告诉它风格和情绪，它给你出3套配色
2版式规划：告诉它内容层级，它帮你排信息优先级
3文案搭配：标题、副标题、正文一起出，风格统一
4灵感搜索：让它帮你找参考风格、描述设计关键词
5生成图片：Midjourney/DALL-E出图，提示词才是核心
📋 实战提示词 · 配色方案
帮我出一个咖啡品牌Logo的配色方案，要求：

【品牌定位】精品手冲咖啡，目标客户是25-40岁都市白领
【风格感觉】温暖、安静、有点日式咖啡馆的调性
【用途】Logo + 包装 + 网页，需要3套方案

每套方案请给出：
- 主色 + 辅色 + 强调色（带HEX色值）
- 一句话说明为什么这3个颜色搭在一起
- 哪种场景适合用这套配色

【约束】
- 不要用大众咖啡品牌的常见配色（棕色+绿色）
- 每套方案要有明显区别
- 色值要可以直接用的
📋 实战提示词 · 版式规划
帮我规划一个手机端活动页面的版式布局，活动是"周末读书沙龙"：

【内容层级】
1. 最重要：活动主题标题
2. 第二：时间和地点
3. 第三：嘉宾介绍（2人）
4. 第四：报名按钮

【风格】简洁、文艺、像书店海报
【屏幕】手机竖屏，宽度375px

请给出：
- 每个内容块占画面的大致比例
- 字号建议（标题/副标题/正文）
- 间距建议（各块之间的留白）
- 颜色分配（标题用什么色、正文用什么色）

【约束】
- 标题不要太小，要一眼看到
- 报名按钮要醒目但不要像广告
- 不要给出"居中排列"这种废话，要有具体数值

📋 实战提示词 · 设计文案一套出
帮我出一套读书沙龙活动的完整文案，要求风格统一：

【活动】周末读书沙龙
【风格】安静、文艺、像朋友间聊天，不要口号感
【用途】海报标题 + 正文 + 报名引导语

请给出：
1. 主标题（8字以内，有画面感）
2. 副标题（补充信息，15字以内）
3. 正文介绍（50字，说清楚活动内容）
4. 报名引导语（1句话，自然不硬推）

【约束】
- 不要写"一场心灵的旅程""遇见更好的自己"
- 不要用感叹号
- 文案可以直接用在海报上，不需要再改

✕ 常见坑

  • "帮我做一个漂亮的设计"——漂亮是什么？AI不知道
  • 只让AI画图不规划——没有版式框架，图再好看也乱
  • 不给情绪词——"温馨""冷淡""活力""高级"这些词才有用
  • 一次想搞定所有——配色、版式、文案分开问，质量更高
  • 色值不用HEX——说了"浅蓝"AI可能给你10种浅蓝

✓ 记住这个公式

  • 风格感觉 + 内容层级 + 具体用途 + 参考关键词 = 可用的设计输出
  • 情绪词比形容词管用："日式安静感" > "简约风格"
  • 配色和版式分开问，别一口气要
  • HEX色值、具体字号、像素间距——数值比描述靠谱

设计提示词的关键词清单

情绪词：温暖、冷淡、活力、安静、高级、文艺、工业、俏皮

风格词：日式极简、北欧风、赛博朋克、复古印刷、手绘插画风

用途词：Logo、海报、网页、App界面、名片、包装、社交媒体图

约束词：手机端、竖版、浅色背景、留白30%、字号18px以上

进阶玩法

  • 先让AI出3套配色，你选一套再往下走版式
  • 把AI出的文案和配色一起喂给出图工具，风格统一
  • 先出文字版式规划，确认后再让它生成图片——顺序对了效率翻倍
  • 喂它一张你喜欢的参考图，让它分析配色和风格，再按这个方向做
  • 让它帮你写出图提示词——你只管描述感觉，它帮你翻译成Midjourney格式
