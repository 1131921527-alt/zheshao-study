# 鑫汇保险 · 银保产品助手 H5 — UI 设计系统

> 面向**银行渠道销售人员**的移动端 H5 / 小程序界面设计系统。
> 目标：让客户经理在手机上快速浏览、对比保险产品，并一键生成面向客户的资料。

## 🎨 设计基础

### 颜色系统（专业稳重 · 金融蓝）
| 角色 | Token | 值 | 用途 |
|------|-------|-----|------|
| 主色 | `--c-primary` | `#1A4DAB` | 主按钮、选中态、关键数据 |
| 主色深 | `--c-primary-700` | `#143A82` | 标题、按压态、渐变收尾 |
| 主色浅 | `--c-primary-050/100` | `#EEF3FC` / `#DBE6FA` | 标签底、图标底 |
| 点缀金 | `--c-accent` | `#C9A86A` | 高端感强调、演示收益数字 |
| 金浅底 | `--c-accent-soft` | `#F7F1E4` | 金色标签底 |
| 页面底 | `--c-bg` | `#F4F6FA` | 冷灰底，降低卡片边界感 |
| 表面 | `--c-surface` | `#FFFFFF` | 卡片、导航、抽屉 |
| 文字1/2/3 | `#1A2233` / `#5A6478` / `#97A1B5` | 主/次/辅助文字 |
| 边框 | `--c-border` | `#E6EAF2` | 分隔线、描边 |
| 成功/警告/错误 | `#16A34A` / `#D97706` / `#DC2626` | 状态语义色 |

**对比度**：主蓝 `#1A4DAB` 对白底 ≈ 7.4:1；金 `#C9A86A` 仅作点缀不参与正文，满足 WCAG AA。

### 字体系统
- **字体族**：`-apple-system, "PingFang SC", "Microsoft YaHei", system-ui`（移动端原生，零加载成本）
- **字号阶梯**：12 / 13 / 14 / 15 / 16 / 18 / 20 / 24 / 28 px
- **字重**：400 常规、600 半粗（标签/按钮）、700 标题
- **行高**：正文 1.5，标题 1.25

### 间距系统（4px 基准）
`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 px`
页面横向留白统一 20px；卡片间距 12px；模块标题上间距 24px。

### 圆角 / 阴影 / 动效
- 圆角：标签 pill、卡片 12–16px、大卡 20px
- 阴影：3 级（sm/md/lg），hover 仅卡片微抬升
- 动效：fast 150ms、norm 280ms；抽屉/Toast 统一缓动

## 🧱 组件库

### 基础组件
- **按钮**：主按钮（实心蓝）/ 幽灵（浅蓝底）/ 描边（对比场景）。尺寸 13–15px，圆角 pill，按压降饱和。
- **卡片 Card**：白底 + 1px 边框 + 轻阴影，承载产品信息；按压 `scale(.985)` 反馈。
- **标签 Tag**：蓝（险种）、金（主推/热销）、绿（保障类），pill 形态。
- **筛选 Chip**：横向滚动，选中态反白填蓝。
- **搜索框**：pill 形态，顶部固定。
- **底部 Tab 导航**：4 项（首页/产品库/对比/我的），图标+文字，选中变蓝。

### 业务组件
- **产品卡**：名称+标签 / 一句话卖点 / 三要素（起投·期限·险种）/ 演示收益 / 查看按钮。
- **产品详情抽屉 Sheet**：底部上滑，含 hero、关键参数 KV 列表、现金价值演示图、卖点标签、底部双操作（加入对比 / 生成一页纸）。
- **现金价值演示图**：纯 CSS 柱状图，蓝=已交保费、金=预期现价，免图片资源。
- **对比表**：横向表头 sticky，行标题列固定，关键列高亮；最多 3 列。
- **对比浮条**：选中后从底部升起，显示数量 + 清空/开始对比。

### 组件状态
- **交互态**：默认 / 按压（降饱和+缩放）/ 选中（蓝填充）/ 禁用（60% 透明）
- **空态**：产品库无结果、对比未选时的引导文案
- **反馈**：Toast 轻提示（2s 自动消失）

## 📱 响应式与适配
- 设计基准：**390 × 844**（iPhone 逻辑尺寸），外壳模拟真机。
- 实际 H5：流式布局，横向 20px 安全边距；筛选/快捷区横向滑动。
- 小程序：同套令牌可直接映射至 WXSS；底部 Tab 对应 `tabBar`。
- 大屏：建议最大内容宽度 480px 居中，避免手机端组件拉伸。

## ♿ 无障碍
- 对比/选择均有文字数量提示，不依赖颜色 alone。
- 图标+文字双标识，触控目标 ≥ 36px。
- 抽屉、Toast 提供焦点与层级管理；颜色对比达 AA。
- 减少动效：可后续接入 `prefers-reduced-motion` 关闭过渡。
