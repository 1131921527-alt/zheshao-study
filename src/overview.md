# 银保产品助手 H5 — 设计方案概览

## 做了什么
为**银行渠道销售人员**设计了一套移动端 H5 保险产品展示/对比界面，专业稳重金融蓝风格。
- 先建立设计令牌系统（颜色/字体/间距/圆角/阴影/动效），再从令牌派生组件，符合「设计系统先行」。
- 产出**可交互高保真原型**（手机外壳 + 真实点击流程），不是静态图。

## 核心结构（4 Tab）
1. **首页**：客户经理身份卡 + 数据概览 + 快捷入口（产品库/对比/利益演示/一键出单）+ 热门推荐。
2. **产品库**：搜索 + 险种筛选 chips + 产品卡列表。
3. **对比**：勾选产品（≤3）→ 底部浮条 → 横向对比表（险种/投保年龄/交费/期限/起投/核心优势）。
4. **我的**：档案 + 菜单（收藏/业绩/话术/主题/设置）。

## 关键交互
- 产品卡点击 → 底部上滑**详情抽屉**（参数 KV + 现金价值演示图 + 卖点 + 加入对比/生成一页纸）。
- 现金价值演示用**纯 CSS 柱状图**（蓝=已交、金=预期现价），零图片资源、加载快。
- Toast 轻提示、对比浮条、空态引导，均符合移动端习惯。

## 设计要点
- 主蓝 `#1A4DAB` + 金 `#C9A86A` 点缀，传递信任与高端感；对比度达 WCAG AA。
- 4px 间距基准、统一 20px 安全边距、卡片按压微反馈，视觉一致。
- 触控目标 ≥36px，图标+文字双标识，适配销售场景单手操作。

## 交付文件
- `index.html` — 可交互原型（直接浏览器打开，手机尺寸预览）
- `design-system.md` — 完整设计系统文档（令牌/组件/响应式/无障碍）
- `overview.md` — 本概览
