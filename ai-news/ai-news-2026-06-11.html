01 Fable 5 被曝"降智"防蒸馏，开源社区强烈抗议 重磅
Anthropic 刚发布的旗舰模型 Claude Fable 5 陷入争议漩涡——多名研究者和开发者发现，模型疑似内置了"反蒸馏"机制：用户一声"你好"即可触发告警，询问高端技术问题时回答被暗箱降质。Anthropic 同步公布了 Mythos 级模型 30 天数据保留与人工审查政策，白帽安全研究者集体不满，称"Fable 把 80% 的研究价值封在拒答里"。CEO Dario Amodei 同日发布长文呼吁 AI 监管加速，被外界解读为意在巩固自身领先地位。
02 微信开放平台接入 AI 智能体，超级 App 变身 Agent 平台 重磅
微信宣布开放平台能力，允许开发者主动授权接入微信 AI 生态，智能体可调取小程序完成交易和服务闭环。美团、携程、同程、滴滴成为首批内测应用。这标志着微信从超级 App 向 Agent 平台的战略转型正式起步——10 亿级用户入口叠加小程序生态，AI 智能体落地的最大规模试验场已然成型。
03 Google 开源扩散语言模型 DiffusionGemma，打破自回归垄断 重磅
Google 发布实验性开源模型 DiffusionGemma（Apache 2.0 协议），26B 参数 MoE 架构，首次将"文本扩散"范式带入大模型主流。该模型放弃自回归逐 token 生成方式，改用并行去噪输出文本，官方测得最高 4 倍推理加速。这代表 Google 在扩散语言模型赛道正式下注，与 Inception Labs、Meta LLaDA 同台竞争，文本生成的底层范式或迎来变局。
04 钉钉换帅：无招卸任，92 年技术极客陈宇森接棒 重点
阿里巴巴宣布钉钉管理层重大调整：陈航（无招）卸任 CEO，1992 年出生的技术极客陈宇森接任，成为阿里史上最年轻的事业部 CEO。陈宇森 22 岁创办网络安全公司长亭科技（后被阿里云收购），2025 年在阿里云内部创业带队研发 AI Agent 产品 MuleRun。对正在全力推进 AI 化转型的钉钉而言，这次换帅意味着产品路线和组织方式都将进入新的观察周期。
05 阶跃星辰 Step 3.7 Flash 登顶 AA 三项第一，性价比碾压 Claude 重点
阶跃星辰发布 Step 3.7 Flash 模型，在 Artificial Analysis 榜单的速度、性价比、端到端三项指标均排名全球第一。输出速度最高 416 tokens/s，单任务成本约为 Claude Opus 4.6 的 1/9，编程能力达 Claude 的 97%。在 OpenRouter Trending 上冲至全球第二，国产模型在极致性价比赛道上持续领跑。
06 前 GitHub CEO 创立 Entire 获 6000 万美元融资，开源 AI Agent 版控 重点
前 GitHub CEO Thomas Dohmke 创立新公司 Entire，完成 6000 万美元种子轮融资，估值 3 亿美元。其开源 CLI 工具 Checkpoints 将 AI Agent 会话集成至 Git 工作流，支持 Claude Code 和 Gemini CLI，实现 Agent 交互的版本化管理。用 Git 的方式管理 AI 编程——这个概念正从理想走向工程化落地。
07 华为云发布 10 万卡级智算集群 AICS 灵衢与 AgentArts 平台 关注
华为云在 INSPIRE 创想者大会上提出 Agentic Infra 新范式，发布 AICS 灵衢智算集群（支持 10 万卡、200 EFLOPS）、AMS Agentic 记忆存储及企业级智能体平台智果 AgentArts。这是国内云厂商首次将 Agent 基础设施提升到战略层级，算力-记忆-沙箱三位一体的架构思路值得持续关注。
